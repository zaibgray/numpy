# NumPy Notebook

This is my personal notebook where I'm learning NumPy. I made it mainly for myself, but sharing it here in case it helps someone else too.

It's just one Jupyter notebook (`.ipynb`) with notes and code examples, going through NumPy basics step by step.

## What's inside

- Creating arrays
- Indexing and slicing
- Reshaping arrays
- Array math and broadcasting
- Useful NumPy functions
- Small examples I used while learning

(This list matches roughly what's in the notebook — update it if you add more topics.)

## How to use it

1. Clone the repo:
```bash
git clone https://github.com/zaibgray/numpy.git
cd numpy
```

2. Install NumPy and Jupyter (if you don't have them):
```bash
pip install numpy jupyter
```

3. Open the notebook:
```bash
jupyter notebook
```

Then just run the cells one by one.

I wanted a simple place to practice NumPy and keep notes for myself. If it helps you learn too, that's a bonus.
